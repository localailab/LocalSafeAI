# LocalSafeAI

**LocalSafeAI** は、完全オフラインで動作する **ローカル生成AIドキュメントシステム（文書RAG）** です。  
クラウドファンディングサイト：https://camp-fire.jp/projects/896411/view  
上記クラウドファンディングから立ち上がったプロジェクトになります。  
クラウドファンディング実施は2025年11月30日まで  
目標金額達成の場合はプロジェクトは以降も続きます。  
ネットワークに接続できない環境でも、AIが社内文書を理解して検索・要約・回答します。  

---

## プロジェクト概要

LocalSafeAI は、セキュリティ制約によりクラウドAIを使えない現場に  
「安全に使える生成AI」を届けることを目的としたデスクトップアプリケーションです。

- すべての処理がローカルで完結（外部通信なし）  
- PDF / Word / TXT / CSV などの文書をAIが検索・要約  
- `.gguf` 形式のローカルLLMに対応
- タグ付けによる文書整理・検索が可能  
- 医療・法務・教育・金融・行政など閉域環境での利用を想定
