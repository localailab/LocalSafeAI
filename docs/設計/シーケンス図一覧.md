## 🔐 login()

```mermaid
sequenceDiagram
    participant UI as Next.js (UI)
    participant IPC as pywebview.api
    participant APP as Python Backend
    participant DB as PostgreSQL

    UI->>IPC: login({ username, password })
    IPC->>APP: 呼び出し(login)
    APP->>DB: SELECT * FROM users WHERE username=?
    DB-->>APP: { user_id, password_hash }
    APP->>APP: パスワード照合（bcrypt）
    APP->>DB: INSERT INTO sessions (user_id, token, expires_at)
    DB-->>APP: OK
    APP-->>IPC: { user_id, token, expires_in }
    IPC-->>UI: JSONレスポンスを返す
```

## 🔍 search_vector()

```mermaid
sequenceDiagram
    participant UI as Next.js
    participant IPC as pywebview.api
    participant APP as Python Backend
    participant FAISS as faiss.Index
    participant DB as PostgreSQL

    UI->>IPC: search_vector({ query, top_k: 5 })
    IPC->>APP: 呼び出し(search_vector)
    APP->>APP: queryをembedding化
    APP->>FAISS: search(embedding)
    FAISS-->>APP: 類似ベクトルIDリスト
    APP->>DB: SELECT text_chunk FROM embeddings WHERE id IN (...)
    DB-->>APP: 該当テキスト返却
    APP-->>IPC: { results: [...] }
    IPC-->>UI: 検索結果を一覧表示
```

## ✅ 全体フロー要約

```mermaid
graph TD
    A["Next.js UI"] -->|IPC| B["Python Backend"]
    B --> C["PostgreSQL DB"]
    B --> D["Vector Index (.faiss)"]
    B --> E["Local Storage (npy files / models)"]
    A -->|設定操作| B
    A -->|検索操作| D
    A -->|アップロード| E
```

---

### 💡ポイント

* すべての通信は **IPCベース（ポートレス）**。
* DB通信は UNIXソケットで直接接続。
* FAISSは Python内部メモリ上で処理。
* `.npy` や `.faiss`、モデルは Local Storage 上で管理。
* UIは Next.js 静的出力（`next export`）を使用。
