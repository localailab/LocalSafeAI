# 機能要件

## 1. プロジェクト名
LocalSafeAI （ローカルセーフエーアイ）

---

## 2. 概要

本システムは、インターネットに接続できない環境でも動作する生成AIデスクトップアプリである。  
ユーザーのローカル環境に保存された文書ファイル（PDF、Word、TXT、CSVなど）を読み込み、  
質問応答・検索・要約などを行う。  
また、使用する大規模言語モデル（LLM）はユーザーがアップロードした **gguf形式モデル** を利用する。  
ただし、デスクトップアプリ購入者には弊社でテストした最適なモデルを同梱する。  
全ての処理はローカル環境で完結し、外部通信は一切行わない。

## 4. 機能フロー

### 4.1 文書アップロード
1. ユーザーがファイルを選択しアップロードする。  
2. アプリが文書をテキスト化し、分割・ベクトル化（embedding）を実施する。  
3. ベクトル情報をローカルDBに登録する。  
4. 必要に応じて、ユーザーが文書にタグを付与する。  

### 4.2 タグ付けと検索
1. 登録済み文書に対して、ユーザーが任意のタグを付与・編集・削除できる。  
2. タグ情報はローカルDBで管理される。  
3. ユーザーはタグを条件に文書をフィルタリング・検索できる。  
4. タグ情報はRAG検索時の検索対象絞り込みにも利用できる。  

### 4.3 モデルアップロード
1. ユーザーがローカルの `.gguf` 形式モデルファイルを選択する。  
2. システムがモデルをローカルにロードし、推論モード（CPU/GPU）を設定する。  
3. モデルは外部通信を行わず、完全にローカルで実行される。  

### 4.4 クエリ処理・回答生成
1. ユーザーが質問を入力する。  
2. システムが質問文をベクトル化し、タグ情報を含む条件検索を実施する。  
3. 検索結果（関連文書の抜粋）をLLMにコンテキストとして渡す。  
4. LLMが回答を生成し、結果をチャット画面に表示する。

---

## 6. 要約

ユーザーのローカル環境に保存された文書を検索し、  
ユーザーがアップロードした gguf 形式のローカルLLMにより回答を生成する、  
完全オフライン型の文書RAGシステムである。  
文書にはタグを付与でき、タグ情報を利用して効率的な検索・回答生成が可能となる。
