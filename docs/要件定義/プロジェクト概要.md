# 🧠 オフラインで安全に使える生成AIデスクトップアプリ  
## 〜 社内文書を読んで答えるローカル文書RAGシステム 〜
### 〜 プロジェクト名：LocalSafeAI(ローカルセーフエーアイ) 〜


---

## 🌐 プロジェクト概要

「ネットに繋げなくても、AIが社内の資料を読んで答えてくれる」  
そんな **安心・安全な生成AIデスクトップアプリ** を開発するプロジェクトです。

このアプリは、**インターネット接続なしで動作する生成AI** を搭載し、  
ローカル環境に保存された **PDF・Word・テキスト** などの文書を読み込み、  
質問応答・要約・検索などを行うことができます。

---

## 🎯 コンセプト

> 「AIを使いたくても使えなかった現場に、AIの力を届ける」

ChatGPT や Gemini などの生成AIは非常に高性能ですが、  
どれもオンライン接続が前提です。  
しかし、現場では次のような制約があります。

| 分野 | 制約・課題 |
|------|-------------|
| 🏥 医療現場 | 患者情報を扱う端末はネットに繋げられない |
| ⚖️ 法律・行政 | 契約書・裁判資料など、外部送信が禁止されている |
| 💼 金融機関 | 顧客情報保護のため、クラウドAI利用が制限されている |
| 👩‍🏫 教育現場 | 成績・教材データをクラウドに出せない |
| 🖥️ システム管理 | クラウドを使わずにAIを導入したい |

このプロジェクトは、**こうした「AIを使えない環境」でも安全にAIを使えるようにすること**を目的としています。

## ⚙️ 主な機能

- **オフライン動作対応**  
  → 完全ローカル環境でAIが動作。外部送信は一切なし。  

- **文書理解・検索・要約**  
  → PDF / Word / TXT / CSV ファイルを読み込み、内容に基づく回答を生成。  

- **ローカルRAG（Retrieval-Augmented Generation）**  
  → ユーザー自身のファイル群をベースにAIが応答。  
  → 「この報告書のA社の部分を教えて」などの質問に対応。  

- **日本語最適化LLM**  
  → 表記揺れや曖昧表現への対応を強化。  
  → ハルシネーション抑制と高精度回答を両立。

## 🔍 RAG（検索拡張生成）とは？

**RAG = Retrieval-Augmented Generation**  
AIが「検索した知識」をもとに回答を生成する仕組み。

このアプリでは、クラウドではなく **ローカルファイルを検索対象** とします。  
ユーザーの文書をベクトル化し、質問に関連する情報を抽出してから回答を生成します。

📘 例：  
> 「生徒Aの成績表の傾向を要約して」  
→ AIがローカルに保存されたPDFを解析し、該当部分を抽出して回答。

## 🧱 技術的課題と挑戦

1. **高精度 × 軽量モデルの両立**  
   - VRAM制約と精度のバランス調整  
2. **日本語特有の表記揺れ・曖昧性への対応**  
   - 専用トークナイザー・日本語embeddingを採用  
3. **ハルシネーション抑制**  
   - RAG構造・スコアフィルタリングで制御  
4. **ローカル運用最適化**  
   - CPU / GPU両対応、モデルサイズの切替機能
